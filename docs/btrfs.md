# Legacy Btrfs conversion history

This page is retained as historical context only. It is not part of the native clean-install flow, and the legacy boot-layout and filesystem-conversion commands are retired and fail closed.

The signed Omarchy Silicon native installer, journaled migration, and recovery contract are not yet shipped. There is no supported command or copied procedure for converting an existing installation, changing boot layout, or encrypting a filesystem.

Do not run conversion commands from old checkouts, cached downloads, or third-party instructions. The standalone command names remain only as disabled tombstones so stale invocations cannot silently mutate a system while the native installer and recovery work remain unresolved.

Open residuals are the native installer, journaled recovery, physical qualification, support, and release evidence. This document makes no compatibility or release-readiness claim.
